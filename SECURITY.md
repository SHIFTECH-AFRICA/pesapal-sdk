# Security policy

Please report security vulnerabilities privately to Shiftech Africa at `info@shiftech.co.ke`. Do not open a public issue for credential exposure, payment verification bypasses, sensitive logging, or dependency vulnerabilities with a working exploit.

Include the affected version, impact, reproduction steps, and a proposed mitigation when available. Never include real Pesapal credentials, bearer tokens, cardholder data, or unredacted production payment payloads.
